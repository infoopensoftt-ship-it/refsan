# ✅ Play Store Yayın Kontrol Listesi

## 📋 Yayından Önce Hazırlanacaklar

### 1. Teknik Gereksinimler
- [ ] AAB dosyası oluşturuldu (`app-release.aab`)
- [ ] Keystore dosyası güvenli yerde saklandı
- [ ] Keystore şifreleri not edildi
- [ ] Uygulama test edildi ve çalışıyor

### 2. Görsel Malzemeler
- [ ] Uygulama ikonu (512x512 PNG)
- [ ] Feature graphic (1024x500 PNG/JPEG)
- [ ] En az 2 ekran görüntüsü (telefon için)
- [ ] Tüm görseller kaliteli ve net

### 3. Metin İçerikleri
- [ ] Kısa açıklama hazırlandı (80 karakter max)
- [ ] Tam açıklama yazıldı (4000 karakter max)
- [ ] Sürüm notları hazırlandı

### 4. Google Play Console
- [ ] Geliştirici hesabı açıldı (25$ ödendi)
- [ ] Hesap onayı tamamlandı

---

## 📱 Play Console'da Yapılacaklar

### Dashboard Görevleri (Set up your app)

#### Policy (Politika)
- [ ] App access - Erişim ayarları yapıldı
- [ ] Ads - Reklam durumu belirtildi
- [ ] Content ratings - İçerik derecelendirmesi tamamlandı
- [ ] Target audience - Hedef kitle seçildi
- [ ] News app - Haber uygulaması değil işaretlendi
- [ ] COVID-19 - COVID uygulaması değil işaretlendi
- [ ] Data safety - Veri güvenliği bilgileri girildi
- [ ] Government apps - Devlet uygulaması değil işaretlendi
- [ ] Financial features - Finans özelliği yok işaretlendi
- [ ] Health - Sağlık özelliği yok işaretlendi

#### Store Settings
- [ ] App category - Kategori seçildi (Business)
- [ ] Store listing - Mağaza bilgileri tamamlandı
  - [ ] Uygulama adı
  - [ ] Kısa açıklama
  - [ ] Tam açıklama
  - [ ] Uygulama ikonu yüklendi
  - [ ] Feature graphic yüklendi
  - [ ] Ekran görüntüleri yüklendi (min 2)
  - [ ] İletişim bilgileri girildi

#### Release
- [ ] Countries/regions - Ülkeler seçildi
- [ ] Production - İlk sürüm oluşturuldu
  - [ ] AAB dosyası yüklendi
  - [ ] Sürüm adı girildi
  - [ ] Sürüm notları yazıldı
  - [ ] Rollout başlatıldı

## ⏳ Yayın Sonrası

### İnceleme Aşaması (1-7 gün)
- [ ] "App being reviewed" e-postası alındı
- [ ] İnceleme sonucu bekleniyor
- [ ] E-posta bildirimlerini kontrol et

### Onay Sonrası
- [ ] "App approved" e-postası alındı
- [ ] Uygulama Play Store'da görünüyor
- [ ] Uygulama linki test edildi
- [ ] Link müşterilerle paylaşıldı

## 🔄 Sürekli Bakım

### Haftalık
- [ ] Kullanıcı yorumlarını kontrol et
- [ ] Yorumlara cevap ver
- [ ] Çökme raporlarını incele

### Aylık
- [ ] İstatistikleri gözden geçir
- [ ] İndirme sayılarını kontrol et
- [ ] Kullanıcı tutma oranlarını incele

### Her Güncelleme Öncesi
- [ ] versionCode +1 artırıldı
- [ ] versionName güncellendi
- [ ] Yeni özellikler test edildi
- [ ] Sürüm notları hazırlandı
- [ ] Aynı keystore kullanıldı
- [ ] Yeni AAB oluşturuldu

- [ ] Keystore dosyası paylaşılmadı

- [ ] Analitik veriler takip ediliyor
- [ ] Kullanıcı geri bildirimleri değerlendiriliyor
